# go-blog-aggregator

**Gator CLI** позволяет добавлять RSS-ленты со всего интернета, сохранять посты в базу данных PostgreSQL, подписываться и отписываться от лент других пользователей, а также просматривать сводки агрегированных постов прямо в терминале.

## 🚀 Необходимые компоненты
Для запуска программы нужно установить **две** вещи:
1. Go версии 1.23 или выше ([официальная инструкция](https://go.dev))
2. PostgreSQL версии 16 или выше ([инструкция по установке здесь](https://www.postgresql.org))

Выполните команды `go version` и `postgres --version` в терминале, чтобы убедиться, что Go и PostgreSQL установлены корректно.

## :minidisc: Установка
Чтобы начать использовать:
1. Клонируйте репозиторий с помощью `git clone https://github.com/englandrecoil/go-blog-aggregator`
2. Перейдите в созданную папку и соберите проект: `go build -o gator`
3. Создайте символическую ссылку для системного использования: `sudo ln -s $(pwd)/gator /usr/local/bin/gator`

## :spiral_notepad: Конфигурация
Создайте файл конфигурации `.gatorconfig.json` в домашней директории со следующим содержимым:
```json
{
  "db_url": "postgres://username:@localhost:5432/database?sslmode=disable"
}
```
Не забудьте заменить _username, password, database_ на данные вашей базы данных.

## :keyboard: Использование
После установки вы можете запускать `gator` из любой директории. Просто используйте `gator <command> [аргументы...]` в терминале. Но сначала необходимо:

Создать нового пользователя:
```bash
gator register <имя>
```

Добавить RSS-ленту:
```bash
gator addfeed <url>
```

Запустить агрегатор:
```bash
gator agg 30s
```

Посмотреть доступные посты:
```bash
gator browse <кол-во>
```

Другие доступные команды приведены ниже:
| Команда  | Описание |
| ------------- | ------------- |
| `gator login <имя>`  | Войти под уже существующим пользователем |
| `gator register <имя>`  | Зарегистрировать нового пользователя |
| `gator feeds` | Показать все доступные ленты |
| `gator users` | Показать всех пользователей |
| `gator follow <url>` | Подписаться на существующую ленту |
| `gator unfollow <url>` | Отписаться от существующей ленты |
| `gator reset` | Удалить всех пользователей безвозвратно |
